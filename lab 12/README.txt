LAB 12 - AGE AUTHORIZATION (DARK TEAL DESIGN)

FILES
- index.html: Age verification form.
- check_age.php: PHP age-checking logic and result page.
- style.css: Dark responsive styling.

INSTALLATION
1. Copy these files into C:\xampp\htdocs\lab12\
2. Replace the previous files.
3. Start Apache in XAMPP.
4. Visit http://localhost/lab12/

RULE
- Age below 18: Not eligible.
- Age 18 or above: Eligible.

MySQL is not required.
