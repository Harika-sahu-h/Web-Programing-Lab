LAB 11 - ATTRACTIVE PHP DATE, TIME AND DAY WEBPAGE

Files:
- index.php: PHP generates the initial date, time, and day.
- style.css: Responsive webpage design.
- script.js: Updates the visible clock every second.

HOW TO RUN:
1. Start Apache in XAMPP.
2. Extract this ZIP file.
3. Copy index.php, style.css, and script.js into:
   C:\xampp\htdocs\lab11\
4. Replace the old index.php and style.css when asked.
5. Open http://localhost/lab11/
6. If the old design remains, press Ctrl + F5.

PHP uses Asia/Kolkata timezone and date(). JavaScript refreshes the visible
clock every second without reloading the page. MySQL is not required.
